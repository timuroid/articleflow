# Реальные модельные испытания 026

- `results.json` — сводка пяти конфигураций, всех 16 вызовов и их общей стоимости.
- [Методика, ошибки и ограничения](../../docs/research/live-026.md).

Документы собственные синтетические. Полные request/response/settings и отчёты
упакованы локально в evidence.json.gz, но НЕ опубликованы в GitHub: автоматическая
проверка отклонила непрозрачный сжатый архив. Его SHA-256 сохранён в results.json
как local_evidence_sha256. Независимое закрытое хранение пока не обеспечено;
публичная сводка не заменяет первичные ответы и не позволяет полностью повторить
исторические вызовы без доступа к локальным материалам.

Typography воспроизводится `scripts/benchmark_long025.py:generate`, stories —
`tests/test_stories026.py:make`, seeds 1/2 для эталонов, 23/31 для переноса.
Метки генератора моделям не передавались. Отдельный student-only контроль
использовал evaluator-prepared шаблон и отмечен отдельно. Новый запуск через
`experiment_model026.py` требует API и существующего журнала бюджета.
