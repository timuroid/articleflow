# Корпус перестановок 024

Генератор: [benchmark_order024.py](../../scripts/benchmark_order024.py).
Один обучающий текст (seed 1), три новых текста (seeds 3, 7, 11), четыре роли.
Для каждого нового текста проверены все 24 перестановки после нейтрализации
оформления: всего 72 случая, 72 точных результата в зафиксированной среде.

[results.json](results.json) содержит все случаи, порядок и результаты.
Это тест компилятора с известными ролями; API attempts=0, fresh model trials=0.
Три текста одного генератора не являются независимым корпусом реальных статей.
DOCX воспроизводятся командой:

```bash
python scripts/benchmark_order024.py --output artifacts/order024-new
```

Генератор создаёт научно нейтральные искусственные тексты, не содержит эталона
владельца или извлечённых из него фрагментов. Бинарные результаты не нужны для
воспроизведения; не заменяют закрытое хранение реальных документов.
