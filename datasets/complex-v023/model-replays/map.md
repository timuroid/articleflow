# Сохранённые ответы на синтетические документы

25 JSON: teacher/student для article-final3 и nested-resume3, а также
20 ответов Qwen на два отложенных документа. Manifest содержит SHA-256.
Нет request.json, API-ключей, приватного эталона или приватного текста.

Для восстановления пакета: создать соответствующий synthetic DOCX,
вызвать `agent023.run` с явным `caller`, возвращающим очередной сохранённый
JSON и metadata `api_attempts: 0, fresh_model_trial: false`. Для применения
использовать `agent023.apply` аналогично. Это проверяет нынешний компилятор
и сборщик на фиксированном ответе; не прибавлять к свежим model trials.
Перед выводом о качестве сравнить все страницы при одинаковом renderer/fonts.
