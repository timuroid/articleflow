# Внешний DOCX-набор 027

Пять официальных примеров оформления разных конференций; 16 исходных страниц.
Это не синтетические данные и не пять опубликованных исследовательских статей.

- [sources.json](sources.json): официальные страницы, прямые URL, hashes и история скачивания.
- [protocol.json](protocol.json): план проверки до запуска моделей.
- [freeze.json](freeze.json): версия production-кода, hashes реализации и manifest.
- [structure.json](structure.json): число абзацев, секций, таблиц и проблемных конструкций.
- [results.json](results.json): все пять исходов, две версии оформления, семь вызовов и стоимость.
- [Отчёт](../../docs/research/frozen-real-027.md): методика, отказавшие случаи, ошибка evaluator и ограничения.

Скачивание с проверкой hashes: `scripts/download_real027.py`.
Проверка: `scripts/experiment_real027.py`; API включается только флагом `--live`.
Ключ и единый журнал бюджета передаются через private paths, не через Git.

Исходные/изменённые DOCX, рендеры и сырые модельные ответы НЕ входят в публичный
репозиторий, остаются только локально. Закрытая независимая копия не обеспечена.
Публичные исходники можно повторно скачать, если удалённые файлы не изменились.
После этой оценки набор является regression; новый независимый test set нужен
для следующей версии системы.
