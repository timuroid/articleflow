# Состояние ArticleFlow

Дата: 17 октября 2026 года. Основа текущей локальной ветки — публичный `main` на `cd8e890`.

- CLI 0.7 и его первичные публичные отчёты сохранены в GitHub.
- В локальной ветке `codex/web017-recovery` заново реализован Web 017 по продуктовым и техническим контрактам. Это новая реализация, а не найденный прежний релиз с SHA-256 `08825bc5…`.
- Пользовательский эталон найден в локальном архиве вне Work и сверяется по SHA-256 `2a299af6dea621444d6a90c9eb87c339f0a1b6baf1e8579d1ea0338d572f9e7e`. Он хранится только в игнорируемой приватной папке.
- Реальный корпус 010–014, прежняя научная рукопись 014–016, закрытый prompt и usage ledger не восстановлены. Новый синтетический корпус из 19 DOCX воспроизводим из Git и не является их копией.
- В новой Web 017 нет внешнего LLM: до получения prompt, ledger, актуального лимита и действующего ключа платные вызовы отключены. Правильность назначения ролей моделью для нового контракта не измерена.
- Сервис установлен на сервере владельца за существующим Caddy: HTTPS с действительным сертификатом, Basic Auth и backend только на loopback. Проверены загрузка пользовательского эталона с нужным SHA-256, синтетического DOCX, два черновика и ZIP manifest. Они не стали готовыми публикациями: на сервере Arial/Times New Roman подменяются DejaVu и остаются смысловые вопросы.
- Приватные данные сервиса и пароль входа скопированы вне Work в закрытый локальный архив. SHA-256 резервной копии и SQLite integrity проверены; корпус прежнего облачного исследования из этого не восстановлен.
