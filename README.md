# ArticleFlow

ArticleFlow — проект приложения для автоматического оформления научных статей в DOCX по шаблону, извлечённому из другой статьи DOCX. Цель — сократить ручную работу редактора и сохранить научное содержание.

**Состояние:** исследовательский прототип 0.3, 15 октября 2026 года. Есть локальный CLI, разбор реального DOCX, черновик шаблона, renderer, проверки и реальные серии через OpenRouter. [Первый отчёт](docs/research/pilot-001.md) отделяет результаты модели от возможностей шаблона. Готового веб-приложения и обработки сотен статей пока нет.

В новых сериях используются только модели с подтверждённым выпуском после 30 июня 2026 года. Основная — GPT-6.1 Sol, выпущенная 29 сентября; [источники, registry и бюджет](docs/research/model-selection.md). Старые измерения GPT-4.1 остаются историческими и не участвуют в выборе актуальной модели.

Рабочий цикл: DOCX-образец → сильная модель/исследователь → проверенный TemplatePackage → пакет новых статей → малая модель → DocumentPlan → программная сборка DOCX → проверка → ZIP и отчёт. Подготовка шаблона и массовое применение имеют отдельные бюджеты и режимы вызовов.

API-ключи, реальные рукописи, извлечённые шаблоны конкретной статьи и ответы моделей не хранятся в Git. Публичны код, синтетические тесты и числовые результаты.

```bash
python -m pip install -e '.[dev]'
articleflow --help
python -m unittest discover -s tests -v
behave docs/product/scenarios/research-pilot.feature
```

Для PDF нужен `soffice` и зафиксированные шрифты. Для платной серии нужны приватный DOCX, подготовленные исследователем annotations/definitions и `OPENROUTER_API_KEY`; обычные тесты API не вызывают. Полный порядок запуска и границы поддержки — в [описании прототипа](docs/tech/research-prototype.md).
