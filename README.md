# ArticleFlow

ArticleFlow — проект приложения для автоматического оформления научных статей в DOCX по шаблону, извлечённому из другой статьи DOCX. Цель — сократить ручную работу редактора и сохранить научное содержание.

**Состояние:** спецификация 0.2, 15 октября 2026 года. Приложение ещё не реализовано, эксперименты не проведены. Первый приоритет — исследовать применение подготовленного сильной моделью шаблона небольшой моделью за один проход. Целевой веб-продукт принимает сотни статей и выдаёт готовые DOCX и ZIP. Технологический стек и числовые ориентиры — предложения для проверки.

Рабочий цикл: DOCX-образец → сильная модель/исследователь → проверенный TemplatePackage → пакет новых статей → малая модель → DocumentPlan → программная сборка DOCX → проверка → ZIP и отчёт. Подготовка шаблона и массовое применение имеют отдельные бюджеты и режимы вызовов.
