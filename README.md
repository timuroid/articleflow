# ArticleFlow

ArticleFlow — проект приложения для автоматического оформления научных статей в DOCX по шаблону, извлечённому из другой статьи DOCX. Цель — сократить ручную работу редактора и сохранить научное содержание.

**Состояние:** начальная спецификация, 15 октября 2026 года. Приложение ещё не реализовано. Документация задаёт целевое поведение; технологический стек и числовые ориентиры — предложенные решения для проверки на пилоте.

Рабочий цикл: DOCX-образец → черновик шаблона → проверенная версия шаблона → исходная статья → план форматирования → DOCX и отчёт проверки.
