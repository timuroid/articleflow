Новый шаблон

Создать шаблон

Основной путь: разметьте эталоны в Codex и загрузите полученный JSON вместе с теми же DOCX.

Импорт шаблона из Codex

Подготовьте приватные packet.json и codex-prompt.md командой PYTHONPATH=src python scripts/export_semantic_packet037.py ПАПКА ЭТАЛОНЫ.docx.... Передайте их и те же DOCX в Codex; сохраните ответ как teacher.json. Полная инструкция — docs/tech/external-semantic-import-037.md.

Импорт создаст черновик без вызова модели. Перед массовой обработкой проверьте эталоны и спорные правила.

Все эталоны должны соответствовать одному шаблону. Автоматический агент проверяет пересборку и восстановление испорченных копий.
