От образца к проверяемому DOCX

Сначала утвердите оформление по эталону. Затем загрузите статьи и проверьте найденные части. Неопределённые данные остаются черновиком с явными вопросами.

Проверяем установленные шрифты…
01

Эталоны и шаблон

Один или несколько оформленных DOCX одного вида.

Исходные файлы хранятся на этом сервере. Отправка текста внешней модели доступна только с вашим отдельным согласием.

02

Статьи

Обработка продолжается для остальных файлов, если один требует проверки.

Не более 25 МиБ на файл. Исходники и все ревизии остаются доступны.

Один вызов на документ. Расходы ограничены общим бюджетом; ошибки модели сохраняются в отчёте.

03

Проверка и результат

Готовый DOCX доступен только после обязательных проверок. Черновик можно скачать отдельно.

Выберите статью из пакета, чтобы увидеть вопросы, блоки и файлы.
