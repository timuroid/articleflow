Порядок знакомства: продукт → интерфейс → сценарии → архитектура → pipeline → контракты → проверки. Нормативное слово «должен» описывает целевое обязательство реализации, а не уже существующую функцию. Все документы относятся к версии спецификации `0.1` от 2026-10-15.

Требования обозначаются `PRD-*`, сценарии — `SC-*`, архитектурные решения — `ADR-*`. Связи между ними собраны в [приёмке](product/acceptance.md). Неподтверждённые решения и вопросы вынесены в отдельный [реестр](product/open-questions.md).
