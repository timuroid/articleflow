# Допущения и вопросы

Это реестр версии 0.2. Уточнение владельца продукта от 2026-10-15 зафиксировало приоритет применения заранее подготовленного сильной моделью шаблона, исследование одного прохода/минимальной модели и пакетный web-путь. Числовые лимиты и технологические детали ниже остаются предложениями.

| ID | Вопрос | Рабочее предположение | Когда решить / кто |
| --- | --- | --- | --- |
| OQ-01 | Какие образцы и статьи реально обрабатываются? | Нужны 3 образца и минимум 20 разрешённых статей; сейчас не предоставлены | До проверки DOCX-конвейера / владелец продукта |
| OQ-02 | Какие правила нельзя вывести из образца? | Редактор подтверждает обязательность и порядок вручную | До утверждения первого шаблона / редактор |
| OQ-03 | Тип размещения и пользователи? | Веб-приложение, рабочие пространства, сначала небольшая редакция | До инфраструктуры / владелец продукта |
| OQ-04 | Допустима ли отправка рукописей внешней модели? | Только по явному разрешению; провайдер, регион и retention требуют согласования | До внешней обработки / владелец данных |
| OQ-05 | Провайдер и модель? | Сильная OpenAI-модель/исследователь для шаблона; малый planner выбирается по benchmark. Конкретные IDs и direct API/OpenRouter не выбраны | До реальных trials / разработчик и владелец |
| OQ-06 | Какие Word, ОС и шрифты являются эталоном? | Word для проверки результата; LibreOffice только вспомогательно | До визуальной приёмки / редактор |
| OQ-07 | Нужны ли сложные объекты, две колонки и колонтитулы? | Поддержка ограничена матрицей; корпус определит следующие расширения | До фиксации MVP / редактор |
| OQ-08 | Можно ли менять порядок разделов? | По умолчанию нельзя; только явное правило, решение и проверяемые ссылки | До структурных преобразований / редактор |
| OQ-09 | Срок хранения? | Рабочее предложение: 30 дней для статей и результатов, версии шаблонов до архивации/удаления | До пилота / владелец данных |
| OQ-10 | Нагрузка, бюджет и время? | Сотни статей подтверждены; предложение 300 файлов / 2 GiB на batch, 25 MiB на файл. Бюджет trials ещё не задан | До batch/load и платных trials / команда |
| OQ-11 | Нужны пакетная обработка и биллинг? | Batch и ZIP входят в целевой MVP по уточнению владельца; биллинг отложен | Batch-решение зафиксировано 2026-10-15 |
| OQ-12 | Какой юридический статус и лицензия кода? | Лицензия пока не выбрана; права на образцы подтверждаются отдельно | До публичного распространения / владелец |
| OQ-13 | Что остаётся после преобразования в текст? | Измерять I0 text-only отдельно от I1 text+assets и I2 semantic spans; не приписывать plain text утраченную информацию | До подготовки corpus / исследователь |
| OQ-14 | Какая среда задаёт pixel ground truth? | Один фиксированный Word/LibreOffice build и fonts; exact 0 differing pixels — отдельный строгий gate | До первого trial / исследователь |
| OQ-15 | Что означает минимальная модель? | Минимальная измеренная стоимость/latency среди кандидатов при gate; параметры только если известны | До выбора кандидатов / владелец и исследователь |

## Предложенные решения

Python/FastAPI, React/TypeScript, PostgreSQL, Redis и S3-compatible storage — архитектурная гипотеза. Первый технический этап — вручную/с сильной моделью заполненный шаблон, измерительный стенд и renderer, затем one-pass application. Универсальный extractor разрабатывается после проверки применения. [Протокол исследования](../research/study.md) описывает ограничения выводов.

При закрытии вопроса добавить дату, основание и ссылку на ADR или изменённое требование. При изменении предположения обновить связанные сценарии и контракты одним изменением.
