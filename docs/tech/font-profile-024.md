# Изолированный профиль шрифтов

Для точного сравнения фиксируются реальные шрифты и движок отображения.
Название в DOCX не доказывает наличие файла шрифта: Fontconfig может подставить
другое семейство. Проверять нужно также шрифты в полученном PDF.

Если необходимые файлы шрифтов уже доступны на законном основании, можно
использовать отдельный профиль, не меняя системную установку:

```bash
python scripts/configure_fonts024.py /path/to/fonts --output artifacts/font-profile
FONTCONFIG_FILE="$PWD/artifacts/font-profile/fonts.conf" python scripts/cloud_preflight023.py
FONTCONFIG_FILE="$PWD/artifacts/font-profile/fonts.conf" python -c 'from articleflow.web017 import font_audit; print(font_audit())'
```

Тот же `FONTCONFIG_FILE` передаётся процессу приложения и экспериментальным
runner. Применять профиль только при проверке, а собирать результат с другим
набором шрифтов нельзя. Скрипт не скачивает и не распространяет шрифты,
не меняет системные настройки и отказывается перезаписывать готовый профиль.
Профиль содержит абсолютный путь данной установки; создаётся заново при переносе.
Файлы шрифтов и локальный профиль не коммитятся в публичный Git.

`font_audit` проверяет Arial и Times New Roman в четырёх начертаниях на
синтетическом DOCX/PDF. Эта проверка не утверждает наличие всех остальных
семейств произвольного входного документа, например KaiTi или Calibri.
