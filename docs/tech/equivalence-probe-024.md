# Контролируемая проверка эквивалентности свойств

Инструмент `scripts/probe_style_equivalence024.py` исследует, можно ли заменить
варианты свойств одного смыслового контекста одним представителем без изменения
изображения данного документа. Это экспериментальный evaluator; он не изменяет
production-правила и не утверждает универсальную эквивалентность.

## Метод

1. Прочитать DOCX и внешнюю семантическую разметку `assignments/definitions`.
2. Извлечь полный каталог и найти конфликтующие paragraph/character контексты.
3. Для каждого контекста выбрать лексикографически первый style ID из
   наблюдаемых примеров. Это воспроизводимая контрольная интервенция, не
   семантическое обоснование правильности данного варианта.
4. В evaluator-only плане заменить только назначения этого контекста.
   Character spans пересекаются с семантическими диапазонами; текст не меняется.
5. Собрать DOCX, проверить содержание и сравнить все страницы с исходником.
6. Объединить положительные интервенции и повторно проверить общий результат:
   независимый успех отдельных замен ещё не доказывает успех комбинации.

Ограничения: до 100 интервенций и 100 страниц. Модель не вызывается. Структурные
перестановки, пробелы между блоками и layout-конфликты этим инструментом не
исправляются. Полный исходный каталог сохраняется; нет удаления неугодных
свойств, ослабления pixel tolerance или изменения рабочего пакета.

Входная разметка и известный исходный план принадлежат контролю. Их нельзя
передавать runtime student, а число успешных интервенций нельзя объявлять
точностью модели. Даже exact на всех эталонах недостаточен для нового текста:
для принятия нормализации нужны объявленная область применимости и отдельные
held-out проверки, особенно для иных алфавитов и выделений.

## Запуск

```bash
python scripts/probe_style_equivalence024.py \
  --source /path/to/reference.docx \
  --annotations /path/to/annotations.json \
  --output artifacts/equivalence-probe \
  --limit 50
```

`summary.json` содержит результаты отдельных интервенций и комбинации,
`production_rules_modified=false` и `general_equivalence_proven=false`.
Планы, DOCX и PDF сохраняются в каталоге эксперимента. При частном входе они
тоже частные; публично распространяется инструмент и синтетические тесты.
