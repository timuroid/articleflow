# Сохранение выделений входной статьи 0.7

PRD-005, PRD-007, PRD-013, PRD-015. Дополнение к [индексам 0.6](context-rules.md): объявленный sidecar хранит исходные bold/italic/super/subscript, включая границы пробелов и пунктуации. Это I2-подобный вход с исходными выделениями, а не их восстановление из чистого текста. Правила применения целевого оформления и сохранение научного содержания оцениваются отдельно.

`source-marks-0.7` содержит hash нейтрального content, hash исходного DOCX, упорядоченные IDs блоков, их длины и диапазоны `start/end/flags`. Flags — два boolean и одно из `baseline/superscript/subscript`. Неуказанные диапазоны обычные. Fonts, кегль, поля, интервалы, координаты, текст и готовые target styles в payload не включаются. Source hash фиксирует происхождение; сборка проверяет content hash, IDs, длины и непересечение диапазонов.

Компилятор независимо от текста создаёт все 12 комбинаций флагов для каждого разрешённого character style. Изменяет только `w:b`, `w:i`, `w:vertAlign`; шрифты, цвета и прочие свойства остаются выбранными шаблоном/планом. Явные значения отменяют случайно унаследованное выделение. Поддерживаемая оценка флагов соответствует ограниченному resolver прототипа, а не полной модели всех возможностей Word.

`extract-marks SOURCE.docx CONTENT.json MARKS.json` извлекает payload. `apply-context-rules ... --marks MARKS.json` применяет его вместо `--indices`. Одновременное использование отклоняется. `changes.json` содержит `source_marks_used=true`, `strict_I1_eligible=false`, `new_model_calls=0`. Преобразование сохранённого плана не считается новым model trial.

Этот режим не решает неоднозначные отступы, высоту пустых абзацев, цвета и другие визуальные свойства. Не объявлять точное сохранение флагов полным pixel equality. Исходный эталон и предыдущие результаты исследования не изменяются.
