# DOCX и границы совместимости

## Приём пакета

MVP принимает незашифрованный `.docx` Office Open XML Transitional. Проверяются расширение, ZIP signature, `[Content_Types].xml`, `_rels/.rels`, main document part и его content type. MIME от клиента не считается доказательством. Strict OOXML сначала определяется по namespaces и отклоняется с объяснением до появления отдельного проверенного адаптера. DOC, DOCM, RTF, PDF и зашифрованный OLE-контейнер не принимаются.

XML разбирается с выключенными DTD, entity expansion и сетью. ZIP entries не извлекаются по предоставленным путям: запрещены абсолютные пути, `..`, дублирующиеся имена, неоднозначные разделители и некорректные имена. Контролируются суммарный распакованный размер, коэффициент сжатия, глубина XML и число элементов. Внешние relationships не скачиваются.

Предложенные стартовые лимиты, конфигурируемые после пилота: файл 25 MiB, распакованные данные 250 MiB, 10 000 entries, compression ratio 100:1, 30 000 абзацев, глубина XML 128. Превышение любого лимита приводит к `LIMIT_EXCEEDED`. Ограничение числа XML-узлов дополнительно задаётся реализацией по измеренному потреблению памяти; до этого большие файлы не допускаются на production.

## Матрица MVP

«Сохранить» означает перенос XML/бинарных частей и проверку зависимостей; это не разрешение применять к ним любые преобразования. Любой заявленный путь нуждается в fixture.

| Конструкт | Действие v0.1 | Проверка / ограничение |
| --- | --- | --- |
| Абзацы, runs, обычные заголовки | Форматировать по роли | Текст и значимые inline-свойства сохраняются |
| Полужирный, курсив, super/subscript | Сохранять семантическое выделение | Сброс direct formatting только по allowlist |
| Списки и numbering | Сохранять связи и нумерацию; менять стиль абзаца | numId/abstractNumId разрешаются, текст меток не теряется |
| Простые таблицы | Шрифт, интервалы и подтверждённые размеры | Порядок ячеек, объединения и содержимое неизменны |
| Сложные/вложенные таблицы | Сохранить с предупреждением, если page changes безопасны | Иначе review/отказ, не сплющивать в текст |
| Встроенные изображения | Сохранить байты, связь и alt text; пропорциональное уменьшение при явном правиле | Hash бинарной части, размеры и relationship |
| Плавающие изображения и text boxes | Блокировать автоматическое форматирование в v0.1 | Нужен отдельный профиль якорей и порядка чтения |
| Формулы OMML | Сохранить поддерево и связи, менять только внешний абзац | Канонический hash OMML без format-only атрибутов не ослаблять без тестов |
| Старые OLE/MathType, встроенные файлы | Отказ до форматирования | Не растрировать и не терять объект |
| Сноски и концевые сноски | Сохранить текст, IDs и пары reference/definition | Проверить все части, включая специальные separator IDs |
| Гиперссылки | Сохранить текст и URI | Не выполнять сетевой переход |
| Bookmarks, REF, SEQ, PAGE | Сохранить инструкции и идентификаторы, учесть зависимость | Актуальность отображаемых полей может требовать Word; предупреждение |
| Сложные поля и неизвестные field codes | Отказ либо review с запретом зависимых преобразований | Не выполнять код поля |
| Колонтитулы | Сохранить из статьи, менять безопасное оформление | Не копировать автора/название из образца; конфликт правил → review |
| Разделы и колонки | Одноколоночный профиль — базовый MVP | Несколько секций с разными размерами/колонками блокируют v0.1 |
| Комментарии | Сохранить текст и якоря без отправки в LLM по умолчанию | При невозможности сохранить диапазон — отказ |
| Track Changes | Отказ с требованием принять/отклонить в Word | Не выбирать final/original view за пользователя |
| Content controls, SmartArt, charts, altChunk | Отказ в v0.1 | Расширять только после фикстур и инвентаризации зависимостей |
| Макросы, ActiveX, embedded scripts | Отказ | Даже при неверном расширении `.docx` |
| Подписи пакета / IRM | Отказ | Изменение нарушит подпись или права |

## Layout и шрифты

Кегль OOXML хранится в half-points, геометрия страницы — twips, геометрия DrawingML — EMU. Внутренние контракты используют явные единицы, преобразование выполняется в одном слое: 1 pt = 20 twips, 1 inch = 914400 EMU. Не округлять значения между этапами многократно.

Нужно различать `ascii`, `hAnsi`, `eastAsia`, `cs` и theme fonts. Отсутствующий шрифт — предупреждение с перечислением затронутых ролей, а не обещание идентичного результата. Автоматическая замена шрифта разрешается только правилом шаблона и отмечается в отчёте. Бинарное встраивание шрифта не выполняется без разрешённой лицензии.

Пагинация зависит от Word/LibreOffice, версии шрифтов, драйвера и полей. Проверка XML гарантирует параметры оформления, но не отсутствие всех визуальных дефектов. Таблица, выходящая за поля после изменения страницы, требует проверяемого правила адаптации или остановки.
