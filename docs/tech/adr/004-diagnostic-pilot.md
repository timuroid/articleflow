# ADR-004: отделить диагностическую реконструкцию от переносимого шаблона

Статус: принято для исследовательского прототипа 0.3, 2026-10-15. Продуктовые контракты v0.2 не заменены. Связь: PRD-005, PRD-013–015, [пилот](../../research/pilot-001.md).

## Наблюдение

Полученный DOCX содержит несколько вариантов прямого оформления внутри одинаковых смысловых ролей, inline-выделения, двуязычные подписи и группу рисунков в таблице. Lossless-разбор с возвращением всех исходных свойств даёт точные пиксели. Общий каталог ролей пока не даёт их даже с корректной oracle-разметкой. Поэтому один итоговый процент смешивал бы способность модели с неполнотой шаблона и renderer.

## Решение

Сохранить три отдельных контура: instance lossless, role oracle и role model. Instance-каталог назначений на конкретные абзацы никогда не считается шаблоном для новых документов. Oracle использует исходные свойства только для диагностики и не передаётся student. Все варианты исходного оформления сохраняются в приватном evidence; наиболее частый вариант — только исследовательский baseline.

Разрешить временный гибридный renderer с сохранённой геометрией объектов и ресурсов стилей, явно исключив его из строгого I1. Это позволяет уже проверить JSON-план и диапазоны модели, пока нейтральный renderer ещё разрабатывается. Ошибочные результаты хранятся как приватные исследовательские артефакты и не принимаются как готовые документы.

Для новых платных серий допускаются только модели с официально подтверждённым выпуском после 2026-06-30. Основной кандидат — GPT-6.1 Sol; один вызов, общий бюджет и все неуспехи учитываются. Старый GPT-4.1 сохраняется исключительно как история измерений и затрат.

## Альтернативы и последствия

- Сразу хранить все исходные назначения: даёт точность одного файла, но не переносимость; оставлено только контрольным baseline.
- Ждать полного универсального extractor: задерживает проверку главной гипотезы применения; извлечение первого шаблона выполнено исследователем.
- Объявить частичное визуальное сходство успехом: не соответствует критерию владельца; exact gate сохраняется.
- Считать ошибки текущего renderer доказательством непригодности маленьких моделей: такой вывод не делается. Лестница дешёвых кандидатов требует сначала пригодного измерительного контура.

Следующий срез: контекстные варианты оформления, независимые assets и геометрия, полноценные figure groups/captions, spans по текстовым anchors с детерминированным разрешением и режим I2 для сохранения исходной научной семантики. Для каждого изменения нужна отдельная замороженная конфигурация; старые результаты не перезаписываются.
