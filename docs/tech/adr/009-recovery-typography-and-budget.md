# ADR-009: вычисленная типографика и единый бюджет восстановления

Дата: 2026-10-17. Статус: принято для ограниченного среза 019.

## Решение

Восстановить Web по сохранившемуся контракту, сохранив CLI 0.7. В шаблоне хранить эффективные свойства с семантическими контекстами. Модель выбирает роли существующих блоков; код переносит оформление и проверяет содержание. Старый профиль web-017 читается отдельной совместимой веткой. Ошибки модели не исправляются скрытыми повторными вызовами.

Старый детальный ledger отсутствует. Новый этап начинается с read-only provider checkpoint и дополнительного cap 3 USD. Исторические расходы не обнуляются; неизвестный usage сохраняет резерв. После переноса на сервер активный ledger один, локальная копия read_only.

## Альтернативы и последствия

- Копирование только прямых свойств проще, но дало 0/6 точных документов в 018; отвергнуто.
- Сохранение низкоуровневого layout каждого эталонного абзаца не доказывает переносимость; такие source-oracle bindings не передаются новой статье.
- Автоматический repair повышал бы наблюдаемую успешность, но нарушал strict_one_pass и скрывал стоимость; оставлен явный review.
- Полный DOCX renderer с универсальными Word-стилями и многосекционными документами пока не восстановлен. Неподдерживаемые случаи остаются review/отказом.
- FC-match не доказывает шрифты фактического renderer; gate использует DOCX→PDF пробу. Разные версии LibreOffice и fonts могут давать разные страницы.
