# ADR-007: условия выбора и явный payload индексов

Статус: принято для исследования 0.6; правила остаются draft. Связи: PRD-005, PRD-006, PRD-013, PRD-015; [контракт](../context-rules.md).

## Основание

В серии 0.5 модель правильно определила роли всех собранных документов, но ошибалась в вариантах свойств и научных индексах. Каталог альтернатив не задавал условия выбора. Синтетический контрпример показал одинаковый model input при разных целевых назначениях.

## Решение

Слой RulePack связывает варианты с семантическим и структурным контекстом. Подготовка использует размеченный образец; runtime — только предсказанные роли и нейтральную структуру новой статьи. Если одному контексту соответствуют разные исходные стили, правило не выводится. Отсутствующее правило оставляет выбор модели и фиксирует review; частота варианта не подменяет неоднозначность.

Научные super/subscript извлекаются из входного DOCX в отдельный sidecar. При сборке они имеют приоритет над модельным предположением. В sidecar нет целевых шрифтов, pPr, размеров и пагинации. Это изменение входного протокола обозначается явно; его успех не заменяет plain-text benchmark.

Объектные размеры выбираются по контексту фигуры и контейнера. Исходные изображения могут быть растянуты; угадывание размеров по intrinsic aspect ratio не восстанавливает такой образец. Извлечённые layout presets сохраняют наблюдаемый вид, но требуют отдельной проверки на новых иллюстрациях.

## Последствия и альтернативы

Offline replay позволяет измерить вклад правил и индексов без новых API-расходов, но не даёт новой оценки качества модели. Результаты всех исходных попыток, включая невалидную, сохраняются. Даже полное совпадение replay было бы post-hoc результатом на обучающем образце, а не независимым transfer.

Запоминание style ID по номеру абзаца, исходному тексту или авторскому имени запрещено. Безусловный выбор модального варианта не используется. Ручные отклонения образца не объявляются требованиями журнала. Для неоднозначных групп нужно получить дополнительные примеры либо определить желаемое правило редакции; строгий pixel gate пока остаётся непрошедшим.
