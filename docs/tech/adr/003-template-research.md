# ADR-003: TemplatePackage, исследование one-pass и пакетный продукт

Статус: направление принято по уточнению владельца 2026-10-15; конкретное представление/модели предложены и требуют эксперимента. Частично уточняет [ADR-001](001-document-engine.md); [ADR-002](002-versioned-jobs.md) сохраняется.

## Контекст

Предыдущие попытки дешёвого извлечения и применения за один проход были недостаточно успешны. Сначала требуется проверить приложение нового документа к качественно подготовленному шаблону. Есть inline emphasis, служебные labels, подписи и изображения; пользователю нужен поток сотен статей с ZIP.

## Решение

Разделить сильный extractor/ручную подготовку и небольшой article planner. Хранить canonical правила и производные resources в immutable TemplatePackage. Основной кандидат application output — DocumentPlan с block/span/object refs; G-FULL и bounded agent loop сохраняются как исследуемые альтернативы. Измерять 10 fresh trials реконструкции, независимый transfer и стоимость, включая подготовку шаблона.

Рендерить DOCX кодом. Production adapter patch_source дополняется rebuild_neutral для честного stripped-input теста. Batch и ZIP входят в целевой MVP; универсальный extractor других типов документов идёт после доказательства применения на статьях.

## Последствия и границы

One-pass становится проверяемым режимом без скрытых retries/chunks. Plain text не содержит утраченные картинки и произвольное выделение; протоколы различаются явно. 10/10 не гарантирует 100% будущей точности. Package/compiler, полный DOM renderer и pipeline ещё не реализованы, результаты исследования отсутствуют.

ADR-001 больше не исключает G-FULL из исследования и не ограничивает все режимы только patch source. Его независимая проверка scientific payload и сборка кодом остаются обязательными.
