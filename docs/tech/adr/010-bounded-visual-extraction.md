# ADR 010 — полный каталог и два независимых визуальных контроля

Принято 17 октября 2026 для 022.

Потери компактного pPr/rPr нельзя исправлять бесконечным подбором частых
значений. Выбран ограниченный эксперимент с расширением до существующего
полного каталога 0.4 и полной реконструкцией. Альтернатива — сохранять только
доминирующее оформление и скрывать различия — отвергнута. Альтернатива —
считать точный oracle replay доказательством переноса — также отвергнута.

Контрольный план остаётся у оценщика; пакет шаблона содержит каталоги без
назначений по source IDs. Применение компактных профилей с известной потерей
остаётся draft. Физический аудит новой статьи отделён от сравнения эталона.
Последствие: часть ранее ready документов теперь требует проверки; это
выявленная неполнота, а не искусственное ухудшение порога качества.

LLM не нужен для локального выбора между двумя реализованными стратегиями.
Расширение множества действий потребует отдельного контракта, тестов и
лимита; текущий цикл не исполняет произвольный код из документа или модели.

Уточнение после проверки реального эталона: доступ к approval разрешает
только контроль `production-roundtrip-022-v1`, вызывающий рабочий сборщик
на исходном и очищенном входе. Каталог с исходным планом не заменяет его.
Цена решения — невозможность утверждать сложный эталон до доработки
рабочего представления; это предпочтительнее ложного успеха.
