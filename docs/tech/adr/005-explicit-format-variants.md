# ADR-005: полные варианты свойств и явный compiled plan

Статус: принято для renderer control 0.4, 2026-10-15. Связь: PRD-005, PRD-007, PRD-013, PRD-015. Уточняет [ADR-004](004-diagnostic-pilot.md), не объявляет завершённым исследование LLM.

## Основание

Абляции на предоставленном DOCX показали: возврат точных paragraph properties уменьшил долю отличающихся пикселей с 15.5270% до 2.8557%; возврат также полного inline-оформления дал нулевое различие. Modal style на роль и только bold/italic/vertical недостаточны даже при правильном oracle.

## Решение

Хранить все наблюдённые варианты в дедуплицированных каталогах paragraph/character/table/row/cell/section/drawing. В runtime-шаблоне нет текста и назначений блоков. Выбор вариантов находится в отдельном compiled plan; source oracle разрешён только как диагностический контроль. Автоматические условия выбора не притворяются известными.

Разделить ресурсы шаблона и содержимое новой статьи. Собирать основной OOXML body заново без исходного `document.xml`, скрытого skeleton с геометрией и cached page breaks. Геометрию таблиц/рисунков задавать явно; научные OMML-объекты сохранять как проверяемый payload. Поэтому строгий plain-text I1 по-прежнему не заявляется.

## Альтернативы

- Просто копировать исходные абзацы: контроль уже умеет это делать, но не проверяет новый compiler. Отклонено как реализация нового renderer.
- Добавить каждому абзацу отдельную роль: скрывает привязку к экземпляру. Смысловых ролей остаётся 42, а варианты описывают свойства независимо от block IDs.
- Оставить одну модальную настройку: подходит для унификации под выбранный стандарт, но не для заявленного exact reconstruction; сохранено как отдельный старый baseline.
- Просить сильнее модель: не восполнит свойства, которые не способен выразить контракт; исправляется представление до новых расходов.

## Последствия

Контрольный образец можно собрать точно при правильном полном плане. Самостоятельный выбор полного плана моделью ещё не измерен; минимальная подходящая модель не выбрана. На новых документах нужен отдельный compiler выбора/семантический план и независимый gold. Пакет имеет статус `observed_catalogue_not_approved` до подтверждения правил редактором.

Новый формат несовместим с pilot-0.3; используется отдельная версия `catalogue-0.4` и новые команды. Проверки целостности расширены позициями объектов, ссылок и bookmarks. Измерения: [renderer-004](../../research/renderer-004.md).
