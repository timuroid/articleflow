## Изменения

`managed034.run` оборачивает обычный агент028: автоматически собирает replay,
запускает code-agent, требует независимые gates, затем новый полный цикл.
`repair034` сохраняет кандидатные версии, допускает только измеримый частичный
прогресс без регрессий. `sandbox034` исполняет кандидатов в Docker. `engine034`
маршрутизирует операции через ContextVar, не импортируя кандидатный код в host.
`worker034` — фиксированный диспетчер. `probes034` — независимые диагностические
и скрытые регрессии. Web сохраняет profile движка и использует его при обработке.
Включение: `ARTICLEFLOW_REPAIR_IMAGE` указывает заранее собранный образ;
Dockerfile и инструкция находятся в `deploy/`.

Разрешено менять только catalogue.py, typography019.py, rules023.py, order024.py
в отдельном снимке. Нельзя менять host verifier, ожидаемые результаты, provider,
бюджет, генератор тестов или исходники работающего сервиса. Полный агентный
профиль одобряется только после нового семантического прогона.
