# Восстановленный однопользовательский Web 017

**Обновление 019:** актуальное поведение описано в [recovery-019](recovery-019.md): effective typography, модельный контур, ввод пропусков, новые версии и реальный font audit. Ниже сохранено описание исходного ограниченного среза 017/018.

Статус: новая реализация по [карте утраченного релиза](web-017-recovery.md); не прежний код Web 017. Исходник `src/articleflow/web017.py`, интерфейс `src/articleflow/web_static017/`. Запуск: `ARTICLEFLOW_DATA_DIR=/var/lib/articleflow .venv/bin/uvicorn articleflow.web017:create_app --factory --host 127.0.0.1 --port 8769`.

FastAPI работает только на loopback за существующим Caddy с HTTPS и HTTP Basic Auth. Данные размещаются в каталоге сервиса с правами 0700: SQLite, оригинальные DOCX, версии шаблонов, ревизии результатов, ZIP. Файлы и база имеют 0600. Приложение не содержит ключа, закрытого prompt и вызовов LLM. Конфигурация передаёт JS CSRF-токен только после внешней авторизации; все изменяющие методы проверяют заголовок `X-CSRF-Token`. Это контур одного владельца, без изоляции пользователей.

Маршруты `/api/v017`: `config`, `templates` (создание, просмотр, утверждение новой версии), `batches` (до 200 DOCX, последовательно в фоновой задаче), `jobs` (просмотр, PATCH решений с optimistic revision, источник/черновик/final/отчёт/редакторский файл), `exports` (ZIP-снимок с manifest). Одна загрузка ограничена 25 МиБ. Ошибка отдельного задания не останавливает остальные. При перезапуске незаконченные задания помечаются `interrupted`; автоматический повтор отсутствует. Итоговый DOCX и ZIP-раздел `results/` доступны только для `ready`, черновики выдаются отдельно. ZIP всегда содержит manifest со статусом каждого задания.

Ограничения: обработка не переживает перезапуск воркера как очередь с автоматическим возобновлением; нет массового удаления/retention, предпросмотра страниц Word, независимого аудита всех возможных OOXML-конструкций, автоматического назначения ролей моделью и публичного API для многих пользователей. Для production-хранения нужен отдельный резервный контур приватных данных. Не использовать успешные тесты этого локального режима как оценку Qwen или точного оформления на новых статьях.

## Обновление UI 038

Один и тот же статический HTML/JS доступен по `/`, `/documents`, `/templates` и
`/history`; путь определяет видимую область. `/` сохраняется как алиас страницы
загрузки для старых ссылок. На `/templates` таблица показывает версии и статусы,
а `<dialog>` содержит импорт Codex и экспериментальное автоматическое извлечение.
На `/documents` находится только форма загрузки. На `/history` таблицы пакетов и
заданий и существующий просмотр результата; после отправки пакета браузер
открывает `/history?batch=<id>`. Параметр ссылки лишь выбирает запись для
показа: доступ к данным по-прежнему определяет reverse proxy. API v017, SQLite
и схема шаблона этим изменением не меняются. HTTP Basic Auth остаётся в Caddy;
логин `owner`, пароль в `/root/articleflow-http-password` на сервере с правами
0600. Его нельзя передавать через Git или подставлять в исходники.
