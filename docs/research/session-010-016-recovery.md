# Карта промежуточных исследований 010–016

Эта запись восстанавливает **только сведения, сохранившиеся в истории работы**, после возврата рабочей среды к публичному CLI 0.7. Файлы серий 010–016, приватные корпуса, usage ledger и исполняемый код не входят в текущий GitHub checkout. Цифры ниже нельзя выдавать за результат нового запуска или за независимо воспроизводимую таблицу без возврата первичных артефактов.

| Серия | Цель и известный результат | Что нужно восстановить для проверки |
| --- | --- | --- |
| 010 | Переносимый профиль оформления для независимых DOCX; старый I3 gate не должен быть ослаблен. Настройка эвристики и отложенный контроль должны различаться. | Исходники `portable.py`, тесты, протокол, corpus manifest, per-document results. |
| 011 | Сравнение на статьях EPOC, AAMS и USS: сообщалось о 34 новых DOCX с разбиением 7/5/22. При фиксированном контрольном профиле на 19 поддерживаемых документах: Sol 17/19, Qwen 27B 12/19, Luna 10/19; ещё 3 из 22 входов не поддержаны. Лучший offline перенос с автоматически извлечённым профилем — 10/19. Это разные условия эксперимента. | Полные CSV/manifest, права на реальные DOCX, код сборщика, отложенные входы, фиксированный renderer. |
| 012 | Извлечение из нескольких эталонов с наблюдениями, спорными правилами и пользовательским подтверждением. Согласованность нескольких статей не равна универсальному издательскому нормативу. | Протоколы intake, gold-разметку, схемы, ошибки, журналы модели и стоимость. |
| 013 | Проверка распознавания ролей, исправлений подсказок, индексов и ошибок на отдельном корпусе. Отказы HTTP и неверные ответы должны оставаться в знаменателе попыток. | Dataset audit, разметку, полную таблицу attempts и frozen prompts. |
| 014 | Оптимизация под малые модели. В прежнем локальном отчёте Qwen около 27B достигал 65/65 в своём зафиксированном режиме; варианты 1B/2.6B/8B не достигли того же критерия. Этот результат нельзя переносить на другой структурный контракт 017. | Registry моделей с датами релиза, 65 исходных заданий и ответов, ledger, параметры вызовов и независимые проверки смысла. |
| 015 | Предварительная научная рукопись была приведена к **не тому** образцу, что прислал пользователь; успешные внутренние проверки 015 не принимаются как выполнение его требования. | Только исторические отчёты; не использовать ошибочный шаблон для новой сборки. |
| 016 | Исправление рукописи под конкретный пользовательский DOCX «Русского инженера». Описывалось сохранение таблиц, двух изображений, формул и гиперссылок, с проверкой Arial/Times New Roman. | Оригинальный DOCX пользователя, приватный registry/profile, исправленный DOCX, font audit, PDF/изображения и hashes. |

Для серии 011 прежний сводный отчёт отмечал 167 API-попыток, `1.54140797 USD` новых ответов по `usage.cost` и `0.183315 USD` неизвестного резерва. Эти значения исторические; текущий баланс и фактические списания по ним не выводятся. В серии 014 локальный общий cap usage ledger был `14.875251924 USD`; существующий ledger **нельзя создавать заново с нулём**. Подробный источник этих чисел в текущем репозитории отсутствует.

При восстановлении проверить каждый эксперимент по исходному протоколу: состав train/evaluation, использование исходного оформления, наличие оракула, число настоящих вызовов, provider failures, цену, сохранность DOCX и независимость от настроенных на оценке правил. Совпадение одного образца или synthetic replay не считать доказательством универсальности. Новый эксперимент начинается отдельной серией, а не подменяет прежние записи.
