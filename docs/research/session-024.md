# Журнал разработки и проверки 024

Дата: 17 октября 2026. Исходная ветка `codex/web017-recovery`, commit `d84a57c`.
Этот публичный журнал содержит программные изменения и результаты собственных
синтетических проверок. Частные материалы и эксплуатационные сведения исключены.

## Вопрос исследования

Можно ли передать большой моделью переносимые правила структуры и оформления
малой модели через декларативный пакет и детерминированный компилятор, без
дообучения весов? Главный предмет — извлечение и применение DOCX-шаблона.
Передача опыта — интерпретация архитектуры, а не доказанная новая теория.

## Первый срез: исправление порядка

До изменения диагностический пример с правильными ролями сохранял неверный
входной порядок. Добавлены наблюдаемые отношения порядка ролей, стабильная
сортировка безопасных групп и проверка содержания относительно явной биекции.
На новом тексте восстановлен порядок title → abstract → keywords. Через
защищённые границы перенос блокируется. Подробности: [контракт](../tech/structure-024.md).

Offline replay сохранённых ответов 023 после изменения: три обучающих документа
и два held-out документа article/nested снова совпали по всем пикселям.
Новых обращений к моделям в этой проверке нет; не добавлять её к 20 fresh trials.

## Второй срез: режимы и наблюдаемость

Добавлены автоматическое сохранение проверенного пакета, assisted-режим,
необязательные уточнения между итерациями и видимые стадии цикла. Проверки API
используют фиктивного провайдера: они подтверждают оркестрацию, а не качество LLM.
Версия неприменённого уточнения блокирует сохранение. Расход на эти тесты нулевой.
Диагностика конфликтов показывает различающиеся пути свойств, но не объявляет
их эквивалентными и не удаляет различия ради прохождения проверки.

## Проверки программной реализации

135 unittest успешно; исходные две BDD-серии — 30 сценариев / 119 шагов,
добавлены и отдельно исполнены SC-096/097 (ещё 2 сценария / 6 шагов).
Chromium: десктоп и мобильная ширина, нет ошибок JavaScript и горизонтального
переполнения; ввод уточнения переживает опрос статуса, отправка работает.
Тестовая страница использует синтетический статус, не имитирует реальные
результаты языковой модели.

## Полный перебор порядка

[Корпус order-v024](../../datasets/order-v024/map.md): seed 1 обучающий,
seeds 3/7/11 новые тексты; 24 перестановки четырёх блоков для каждого текста.
После нейтрализации оформления получено 72/72 pixel exact с сохранностью
содержания. Роли известны по генератору: это не model accuracy.
Prompt 024 расширен с scientific document на document; новые модельные серии
обязаны фиксировать эту версию и не объединяться с прежними промптами 023.

## Открытые проверки

Перенос на независимые реальные документы, поддержка составных перестановок,
разделение смысловых фрагментов одного абзаца, малые локальные модели и
количественное сравнение автоматического режима с assisted. Эти результаты
пока не получены и не могут выводиться из успешности тестов компилятора.
