# Qwen3.8-27B: сравнение I3 на том же образце

PRD-014, PRD-015, PRD-017. Серия 008 от 2026-10-15 на неизменном CLI 0.7.0: **6/10 полных совпадений** у `qwen/qwen3.8-27b`. Все попытки — свежие вызовы API. Это режим I3, где compiler получает оформление входного DOCX. Исходный gate реконструкции очищенного текста I1/I2 и независимый transfer остаются непройденными.

## Модель и сопоставимость

Выпуск 14 августа 2026 подтверждён [официальным журналом Qwen](https://github.com/QwenLM/Qwen3.8/blob/main/README.md#news). [Карточка разработчика](https://huggingface.co/Qwen/Qwen3.8-27B) указывает 27B параметров языковой части, плотную архитектуру и отдельный vision encoder; общий счётчик Hugging Face округляет все веса до 28B. Модель удовлетворяет запросу «около 30B» и ограничению после июня 2026. Это открытые веса; локальное выполнение и квантизации этим экспериментом не измерены.

До запуска зафиксированы десять попыток, один POST на документ, `reasoning.effort=medium`, `max_tokens=8192` включая reasoning и JSON. Первая попытка проверила совместимость, затем выполнены девять остальных без изменения конфигурации. Нет repair, human edits, повторов вместо неудач или application response cache. Все запросы требуют поддержки параметров, provider fallback выключен; выбор исходного провайдера оставлен OpenRouter, как в серии 007. Реальные provider/model IDs сохранены в CSV, идентификаторы запросов — в приватных артефактах.

Хеши prompt/schema/source/template/content/RulePack проверены и совпадают с [серией 007](source-aware-007.md). Рендеринг: тот же LibreOfficeDev 26.8 и набор шрифтов, 12 страниц, 144 DPI, RGB. Объём входа: 178 блоков и 42 роли. Temperature не передаётся ни одной модели; default sampling и смысл `medium` могут отличаться. Это сравнение API-конфигураций, не изолированное измерение влияния числа параметров.

## Результаты

| Модель | Полное совпадение | API за 10 попыток | Средняя цена документа | Медиана ответа API |
| --- | --- | --- | --- | --- |
| openai/gpt-6.1-sol | 10/10 | $0.2627206 | $0.02627206 | 28.30 с |
| openai/gpt-6-luna | 10/10 | $0.015687685 | $0.0015687685 | 19.27 с |
| qwen/qwen3.8-27b | 6/10 | $0.161924865 + резерв $0.03663608 | неизвестна | 140.05 с |

Qwen: exact roles 6/10, content 6/10, inline 6/10, placements 6/10, pixels 6/10. Полный успех требует всех пяти метрик одновременно. Неудачные попытки сохранены в CSV и summary; они входят в знаменатель 10. Причины: попытка 3: incomplete, length; попытка 5: incomplete, length; попытка 6: incomplete, length; попытка 9: http_error, HTTP_429.

В 3 попытках API сообщил `finish_reason=length`: исчерпан общий бюджет reasoning + JSON. Такие ответы не передавались сборщику, DOCX для них не создавался; отсутствующие pixel metrics в CSV означают «не оценено», а не нулевую разницу. Ошибка лимита — не доказательство неверной классификации оставшихся блоков, но документ в strict one-pass не получен, поэтому попытка неуспешна. Повышение лимита или уменьшение reasoning требует новой отдельной серии; текущая не исправлялась задним числом.

HTTP 429 в попытке 9 относится к `upstream_provider_shared_pool` Darkbloom. Ответ не содержит generation ID или usage, поэтому стоимость не обнулена: сохраняется резерв $0.03663608. После указанного провайдером интервала 2 секунды выполнялась следующая запланированная попытка 10; попытка 9 не повторялась. Данные provider metadata сохранены приватно, безопасные поля причины включены в CSV. Отсутствующие токены не приравниваются к нулю.

Время ответа Qwen: 26.57–159.88 с. Выход: 7522–8192 токенов, в том числе reasoning 4666–6229. Cached input всего 8192 токенов. Время включает ожидание ответа провайдера и передачу данных, но не сборку DOCX, рендеринг и проверку. Части reasoning не выдаются за дополнительные вызовы модели.

Тариф в снимке [каталога OpenRouter](https://openrouter.ai/api/v1/models): вход $0.24/1M, выход $2.20/1M, cache read $0.05/1M. Итоговая сумма считается по `usage.cost` фактического маршрута, а не по умножению на рекламную цену. Кеширование провайдером и различная токенизация влияют на сравнение стоимости.

Данные: [все десять попыток](qwen-008-results.csv), [агрегаты, конфигурация, хеши и ограничения](qwen-008-summary.json). Старые результаты 007 не пересчитаны задним числом.

## Бюджет и проверки

Перед серией было $2.787404085 накопленных расходов. Консервативная оценка десяти запросов без надежды на cache hits — $0.36636080. Подтверждённые расходы новой серии **$0.161924865**, суммарно в едином ledger **$2.949328950**; дополнительно сохраняется неопределённый резерв **$0.03663608**, записей ledger 61. Полная фактическая стоимость серии пока неизвестна; средняя цена не выводится из неполной суммы. Общий предел этапа $5 соблюдён с учётом резерва. Это расходы экспериментов через данный ledger, не проверенный остаток аккаунта OpenRouter. Локальное вычисление и труд исследователя не входят в API-сумму.

Код сборщика, prompt, роли и правила не менялись. Повторная проверка стенда: 57 unittest, 14 Gherkin-сценариев. Перед публикацией сверяются все десять строк с ledger, неизменность входов, полнота серии и отсутствие рукописи/ключей/ответов модели в Git.

## Границы вывода

Один и тот же предоставленный образец использован для шаблона и проверки. Его исходные свойства явно доступны compiler; target oracle и golden PDF доступны только evaluator. Наблюдаемые правила остаются research draft. Требуется совместимость styles/theme/numbering/settings. Новые реальные статьи, Microsoft Word, локальные Qwen и другие квантизации не проверены. Повторы одного документа не являются десятью независимыми документами.

Результат позволяет сравнить три проверенные конфигурации для I3. Он не устанавливает минимальную модель для полного выбора оформления из очищенного текста и не доказывает универсальную точность на новых статьях.

## Воспроизведение

Требуются приватные артефакты pilot-001 и ключ в окружении или отдельном секретном файле. Исходная команда первой попытки:

```bash
PYTHONPATH=src python -m articleflow source-trials \
  artifacts/pilot-001/renderer-v04/package-v2/template \
  artifacts/pilot-001/renderer-v04/package-v2/content \
  artifacts/pilot-001/rules-v06/rules.json \
  private-fixtures/pilot-001/source.docx \
  artifacts/pilot-001/renderer-v04/package-v2/oracle-plan.json \
  artifacts/pilot-001/golden/source.pdf \
  artifacts/pilot-001/qwen-v08/openrouter-models.json \
  docs/research/models.json \
  artifacts/pilot-001/trials/usage-ledger.json \
  artifacts/pilot-001/qwen-v08/qwen-008 \
  --model qwen/qwen3.8-27b --first 1 --repeats 1 \
  --cap-usd 5 --max-tokens 8192 --reasoning-effort medium
```

Продолжение исходной серии использовало `--first 2 --repeats 9` при тех же остальных параметрах. Runner остановился после HTTP 429 в попытке 9; следующая попытка запускалась как `--first 10 --repeats 1` без повторения 9. Уже выполненные run IDs не перезаписывать. Новое независимое повторение требует отдельной папки серии и того же общего ledger; цены нужно проверить заново до резервирования бюджета.
