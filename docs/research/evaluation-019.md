# Серия 019: восстановление рабочего цикла ArticleFlow

17 октября 2026. [Протокол](recovery-019-protocol.md) записан до изменений; [машинные результаты всех серий](evaluation-019.json) сохраняют неудачные попытки. Это новая реализация и новые измерения. Утраченные серии 010–017 не пересозданы побайтово.

synthetic-v1 состоит из 19 файлов: 6 train, 6 парных gold, 6 входов, 1 вход с пропусками. После разработки по ошибкам 018 он **development regression**, не независимый test. На этапе выбора профилей использованы только train-наблюдения; при конфликте исследовательский скрипт выбирает наиболее частый вариант с устойчивым tie-break. Это исследовательская конфигурация, не автоматическое нормативное утверждение редакционного шаблона.

Время 200 файлов не включает сеть production, LLM и холодный font audit. Все 200 были draft: роли требуют подтверждения. Ускорение не доказывает производительность на произвольных статьях.

## Свежие LLM-вызовы

Один запрос на вход, без repair и скрытого повтора. Изменение prompt/контракта начинает отдельную серию. Последующие исправленные серии не заменяют предыдущие неуспехи.

|---|---:|---:|---:|---:|---:|
| Qwen, prompt v1 | 7 | 1/7 | 1/6 | $0.013909920 | 15.16 с |

| Qwen, исправленный контракт | 7 | 7/7 | 6/6 | $0.013941240 | 16.36 с |
| Luna, финальная разметка и шаблоны Sol | 7 | 7/7 | 6/6 | $0.004071725 | 3.91 с |

Ошибки: Qwen v1 принимала библиографическую ссылку за редакторскую заметку; в одном плане нарушила совместимость контекста. Уточнение общего правила ссылок в prompt v2 не устранило дефект словаря: роль editorial была разрешена, одноимённый контекст отсутствовал. После исправления словаря проведена новая серия. Sol вернула HTTP 400, поскольку endpoint требует reasoning; новая отдельная конфигурация low обработала шесть train-эталонов. Ответы HTTP 400 без usage не считаются бесплатными: полный резерв сохранён.

Статус `compiler_status=ready` в модельном evaluator означает контентный контроль при принудительном `fonts_ok=True`; это **не production font gate**. Веб-приложение отдельно проверяет реальные требуемые семейства. Вход с отсутствующими авторами/практической значимостью во всех успешных сериях остаётся draft; модель не дописывает эти сведения.

На малом development-наборе Luna дешевле и быстрее Qwen. Минимальный достаточный размер модели, независимый перенос и стабильность 10 независимых повторов на каждый вход этим исследованием не установлены. Cache-hit влияет на стоимость; особенно малая стоимость student после teacher отражена как наблюдение, не универсальная цена.

## Шрифты, renderer и настоящий эталон

В 018 `fc-match` ошибочно интерпретировался как доказательство шрифтов renderer: bundled LibreOffice использовал Liberation. В 019 это обнаружено по PDF и исправлено отдельным Fontconfig. В неизменном прежнем окружении перенос тоже дал 6/6 (`dev-second`); повтор с настоящими Arial/TNR дал 6/6 (`release-regression`). Поэтому эффект исправления сборщика и смена шрифтов разделены.

Фактические семейства пробы: ArialMT/Arial-BoldMT/Arial-ItalicMT/Arial-BoldItalicMT; TimesNewRomanPSMT и три соответствующих начертания. Серия south запрашивает Calibri, которого нет: её 2/2 означают совпадение candidate и gold при одинаковой подмене, **не наличие настоящего Calibri**. Формулы также используют fallback. Строгий итог по двум семействам с настоящими требуемыми текстовыми шрифтами — 4/4; общий регрессионный pixel gate — 6/6. Три повторных рендера контрольного DOCX имеют одинаковые растровые хеши.

Эталон пользователя проверен по SHA-256 `2a299af6dea621444d6a90c9eb87c339f0a1b6baf1e8579d1ea0338d572f9e7e`. До исправления распознавания организации/города/почты и пустых разделителей — 12 страниц, первая отличалась. После исправления — **12/12 страниц и 0 отличающихся пикселей**, исходный payload/связи сохранены. Это conservation-контроль того же документа, не преобразование новой статьи под его оформление. Никакой посторонний DOCX с сайта не использован.

## Бюджет и воспроизводимость

До нового этапа: provider usage $7.956670174, остаток $3.309577851. Дополнительный предел — $3. Локальная серия: **62 попытки**, подтверждено **$0.118119260**, неопределённый резерв **$1.060285**. Последний read-only баланс при подготовке отчёта — около **$3.192**; API учёта может отставать на один завершённый вызов. Серверный smoke-вызов учитывается дополнительно в наблюдении развёртывания, в том же ledger.

Исторический журнал по отдельным вызовам утрачен; provider checkpoint и прежние сводки сохраняются без повторного суммирования. Подробный prompt, запросы, ответы, ledger, DOCX и PDF остаются приватными; публичны хеши, код, синтетический генератор и числовые результаты.

Команды:

```bash
python scripts/build_synthetic_corpus.py --verify
python -m unittest discover -s tests
behave docs/product/scenarios/research-pilot.feature docs/product/scenarios/structure-web.feature
python scripts/benchmark_recovery019.py --output artifacts/new-regression
python scripts/verify_recovery019.py --output artifacts/new-verification --reference private-fixtures/reference.docx --http
# Следующие команды платные: нужен единый действующий ledger и закрытая конфигурация.
python scripts/evaluate_models019.py --config /private/model.json --output artifacts/new-model-series
python scripts/evaluate_extractor019.py --extractor-config /private/teacher.json --student-config /private/student.json --output artifacts/new-teacher-series
```

Рендер фиксируется через `ARTICLEFLOW_SOFFICE` и при необходимости `ARTICLEFLOW_FONTCONFIG`. Frozen JSON каждого нового evaluator хранит хеши исходников, prompt, manifest и профиль; первоначальные отладочные серии v1 не имели полного source snapshot и имеют меньшую воспроизводимость. Нельзя подменять их финальным кодом при заявлении точного replay.

## Приёмка и оставшееся

Unit/integration: 80 тестов; Gherkin: 21 сценарий, 91 шаг. SC-080–SC-085 впервые имеют исполняемые definitions. Через настоящий браузер проверены загрузка, утверждение шаблона, пропуски, ввод сведений и новая готовая ревизия. Нет данных о переносе на утраченную реальную выборку, сравнении во всех версиях Word, полном визуальном feedback-loop extractor или универсальной типографике. Научная рукопись остаётся явно обозначенным новым черновиком.

После установки проверена ещё одна синтетическая пара непосредственно на сервере: 2/2 точных страниц. Production smoke добавил один вызов Luna; итог 63 попытки, $0.118338590 подтверждено и $1.060285 зарезервировано. [Подробности](../tech/deployment-observation-019.md).
