# Связанные методы: агентный цикл и текстовая оптимизация

Проверены первичные страницы публикаций и аннотации на arXiv. Это краткая карта
для позиционирования, не систематический обзор и не воспроизведение результатов.
Ограничение проекта на свежесть моделей не относится к годам научных источников.

| Работа | Подтверждённая связь | Что следует проверить у нас |
|---|---|---|
| Shinn et al., [Reflexion: Language Agents with Verbal Reinforcement Learning](https://arxiv.org/abs/2303.11366), 2023 | Улучшение решений агента через языковую обратную связь и память без обновления весов | Добавляет ли история ошибок пользу сравнению с последней ошибкой; отделять внешний проверяющий сигнал от самооценки |
| Khattab et al., [DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines](https://arxiv.org/abs/2310.03714), 2023 | Декларативные модельные модули и оптимизация конвейера под метрику; рассматриваются в том числе небольшие модели | Сравнить фиксированную инструкцию и оптимизируемую на development-корпусе; заморозить независимый test до оптимизации |
| Yuksekgonul et al., [TextGrad: Automatic “Differentiation” via Text](https://arxiv.org/abs/2406.07496), 2024 | Текстовая обратная связь используется для оптимизации составной системы | Отдельно измерить вклад текстовой диагностики и визуальных примеров; не называть наш текущий цикл реализацией TextGrad |

Вывод для статьи: сама идея улучшать программу вокруг LLM и передавать обратную
связь текстом уже имеет предшественников. Кандидат на специфический вклад
ArticleFlow — переносимый документный контракт, независимые повреждения,
контроль сохранности и измерение стоимости автономного получения шаблона.
Приоритет такого сочетания ещё требует более полного обзора и сравнения.
Числа из чужих задач нельзя переносить на точность вёрстки DOCX.

В текущий runtime эти библиотеки не добавлены. Предложенные абляции ещё не
проведены; таблица задаёт исследовательские сравнения, а не новые результаты.
