# Проверяемое обучение шаблонов — серия 023

Основной набор измерений зафиксирован 17.10.2026. [Машинная сводка](evaluation-023.json),
[научная рукопись](manuscript-023.md), [контракт](../tech/agent-023.md).

## Что измерено

- 35 свежих обращений OpenRouter: 34 валидных ответа, один HTTP 400;
  известный расход $0.753724935. Неопределённый резерв ошибки сохранён.
- Qwen3.8-27B: 10/10 точных результатов на новой синтетической статье
  (10 страниц) и 10/10 на новом документе с вложенными таблицами (16 страниц).
  Это **два разных документа**, а не двадцать независимых рукописей.
  Все 260 страниц результатов сравнены при 144 DPI, RGB, нулевом допуске.
- Стоимость этих двадцати вызовов: $0.06221447. Задержки и расходы каждого
  обращения находятся в JSON; обучение большой модели считается отдельно.
- Первый цикл nested: 234/236 + 244/244 правильных ролей; восемь unresolved
  в первом документе. После обратной связи: 236/236 + 244/244, оба exact.
  Продолжение после бюджетной остановки — отдельный запуск nested-resume3.
- Частный эталон: свежий поздний вызов дал 161/161 ролей, но 46 конфликтных
  групп и 335 unresolved. Готовность не подтверждена. Последний offline replay
  с соседними ролями/языком/промежутками: 47 групп, 255 unresolved. Изменение
  числа групп связано с разбиением условий; это не рост точности модели.
- Нормализация наследуемых run properties: 12→12 страниц, differing pixel
  ratio 0.00023201192900302014. Кандидат отклонён, в production не включён.

## Данные и ограничения

12 новых синтетических DOCX четырёх семейств, 2131 абзац. Generator:
`scripts/build_complex023.py`. Две колонки прошли контроль сборщика с известной
разметкой; это не измерение LLM. Колонтитулы остаются неподдержанными.

Три реально скачанных публичных DOCX: Мурманский университет, Gostdown,
Воронежский университет. Все три остановлены импортёром; URL, SHA-256 и коды
отказа опубликованы в сводке. Их текст внешним моделям не передавался.
Пустой нескачанный IEEE A4 не включён в число документов. Закрытый пользовательский
эталон идентифицирован исходным SHA-256, а не заменён похожим публичным файлом.

Вход модели содержит текст, структуру и объявленную семантику DOCX. Это не
plain-text I1. В runtime нет oracle и исходных типографических назначений.
Успешные исходные серии на сервере выполнялись промежуточными версиями кода;
их snapshots сохранены. Последняя версия повторно собрала три обучающих
эталона и два отложенных документа с сохранёнными ответами, без API: все
пять pixel exact, все 12 отрицательных контролей обнаружены. Этот replay
не прибавлен к двадцати свежим model trials.

## Проверки кода и интерфейса

Локально: полный набор 127 тестов прошёл; после последних исправлений отдельно
прошли 9 тестов 023. Исполняемый BDD: research-pilot + structure-web, 30 сценариев,
119 шагов. Остальные старые `.feature` являются спецификацией: полный запуск
всех feature-файлов показал 71 сценарий с undefined steps; их нельзя объявлять
пройденными. Проверка JavaScript выполнена отдельно.

Изменены контекстные правила фрагментов, восстановление пустых абзацев,
контроль вложенной топологии и индексов, защита платного вызова от старого
ручного редактора, учёт отсутствующих блоков. Вопросы имеют выдержку и ссылку
на страницу эталона, если координаты найдены. Локальный UI работает без
платного провайдера; серверная приёмка фиксируется отдельным документом.

## Воспроизведение

```bash
python -m pip install -e '.[web,dev,paper]'
python scripts/build_complex023.py --output artifacts/my-complex023
python -m unittest discover -s tests -q
behave docs/product/scenarios/research-pilot.feature docs/product/scenarios/structure-web.feature
python scripts/build_paper023.py --output artifacts/paper/ArticleFlow-023.docx
```

Платные runner `run_agent023.py` и `evaluate_agent023.py` требуют отдельного
закрытого config с действующим ledger и явного разрешения. Штатные тесты
не должны автоматически обращаться к API. Рукопись оформлена отдельным
редакторским генератором; её внешний вид не выдаётся за успех неподтверждённого
реального шаблона. Авторство пока не заполнено.
