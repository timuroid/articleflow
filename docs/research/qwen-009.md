# Qwen3.8-27B без reasoning: отдельная серия 009

PRD-014, PRD-015, PRD-017. Результат от 2026-10-15: **9/10 полных совпадений** в режиме I3 при `reasoning.effort=none`. Во всех 9 ответах с usage провайдер сообщил **0 reasoning tokens**; для HTTP-ошибок usage отсутствует. Все неуспехи сохранены в CSV и summary и входят в знаменатель 10.

## Почему проведена отдельная серия

После первых пяти попыток [серии 008](qwen-008.md) наблюдались три полных совпадения и два `finish_reason=length`. До запуска 009 зарегистрирована гипотеза: отключение reasoning оставит достаточно токенов для всего JSON без потери качества. Все десять попыток medium завершены и сохранены до начала 009. Новая серия адаптивная; её результаты не заменяют неудачи прежней конфигурации.

Модель та же: `qwen/qwen3.8-27b`, плотная языковая часть 27B, выпуск 14 августа 2026 по [официальному журналу](https://github.com/QwenLM/Qwen3.8/blob/main/README.md#news). [Карточка разработчика](https://huggingface.co/Qwen/Qwen3.8-27B) описывает отключаемый thinking; снимок OpenRouter объявляет поддержку effort `none`. Подробности размера и цены — [выбор модели](model-selection.md).

## Условия

Изменился только запрошенный effort `medium` → `none`. Те же `max_tokens=8192`, prompt, JSON-схема, исходный DOCX, нейтральное содержимое, шаблон, RulePack и код CLI 0.7.0; равенство хешей проверено. Temperature не передаётся. Провайдер может менять внутренние defaults при переключении режима: сравниваются API-конфигурации. Один POST на документ, без repair, human edits и application response cache; provider fallback выключен. Первая попытка проверяет совместимость, остальные девять продолжают ту же замороженную конфигурацию.

Модель выбирает 178 ролей блоков из 42 определений, compiler использует объявленное source formatting. Target oracle и golden PDF доступны только evaluator. Полное совпадение требует одновременно roles/content/inline/placements/pixels exact. Тот же LibreOfficeDev 26.8, шрифты, 144 DPI, RGB и 12 страниц.

## Сравнение

| Модель | Effort | Полное совпадение | API за 10 попыток | Медиана ответа API |
| --- | --- | --- | --- | --- |
| openai/gpt-6.1-sol | medium | 10/10 | $0.2627206 | 28.30 с |
| openai/gpt-6-luna | medium | 10/10 | $0.015687685 | 19.27 с |
| qwen/qwen3.8-27b | medium | 6/10 | $0.161924865 + резерв $0.03663608 | 140.05 с |
| qwen/qwen3.8-27b | none | 9/10 | $0.110034095 + резерв $0.03663560 | 94.79 с |

В серии 009: roles 9/10, content 9/10, inline 9/10, placements 9/10, pixels 9/10. Выход 5354–5354 токенов. Время ответа 26.51–145.54 с; сюда не входит сборка и рендеринг. Разная токенизация и provider cache влияют на цену; сумма взята из `usage.cost`, а не рассчитана по каталогу.

В попытке 8 Darkbloom вернул HTTP 429 с `limit_source=upstream_provider_shared_pool` и ожиданием 2 секунды. Runner остановился; после паузы выполнены следующие запланированные попытки 9–10. Попытка 8 не повторялась, fallback не включался. Ответ не содержит usage или generation ID, поэтому сохраняется её резерв $0.03663560. Ошибка инфраструктуры отличается от ошибки ролей, но входит в строгий показатель полной обработки документа. Точность только полученных ответов нельзя объявлять точностью всех десяти запросов.

В первых ответах сериализация тоже различается: medium — 6871 символов и 2 переноса строки, none — 11505 символов и 715 переносов. После JSON-разбора планы равны: `True`; компактная запись занимает 6869 символов в обоих случаях. Удаление reasoning не означает столь же большого уменьшения всего ответа: часть выигрыша расходуется на форматирование JSON. Изменение prompt ради компактного JSON в эту серию не входит и потребовало бы новых измерений.

Машиночитаемые данные: [десять попыток](qwen-009-results.csv), [агрегаты и замороженные входы](qwen-009-summary.json). Полное исследование Qwen содержит 20 свежих запросов в двух конфигурациях; результат 009 не означает, что все 20 были успешны.

## Бюджет и границы результата

Подтверждённые расходы серии 009 — **$0.110034095**; обеих серий Qwen — **$0.271958960**. Всего через общий ledger подтверждено **$3.059363045**, дополнительно сохраняется неопределённый резерв **$0.07327168**, записей ledger 71; предел этапа $5 соблюдён вместе с резервом. Полная сумма Qwen пока неизвестна из-за HTTP 429 без usage в обеих сериях; эти запросы не объявляются бесплатными. Это не проверенный остаток аккаунта и не полная себестоимость локального вычисления и труда.

Код сборщика и правила не менялись; 57 unittest и 14 Gherkin-сценариев прошли. Все попытки сверены с ledger, проверены один запрос и отсутствие repair/cache подмены. Источники дат и снимки API сохранены отдельно от публичных числовых данных.

Вывод относится к одному уже известному образцу и I3 с исходным оформлением. Исходный I1/I2 gate, новые реальные статьи, Word, импорт несовместимых styles/resources, локальная Qwen и квантизации не проверены. Шаблон остаётся research draft. Повторы одного образца не доказывают 100% надёжность на новых документах. Размер закрытых OpenAI-моделей неизвестен, поэтому этот результат не устанавливает минимальное число параметров среди всех кандидатов.

## Воспроизведение

Использовать команду из [008](qwen-008.md#воспроизведение), заменив выходную папку на `artifacts/pilot-001/qwen-v08/qwen-009` и `--reasoning-effort medium` на `--reasoning-effort none`. Первый вызов: `--first 1 --repeats 1`; продолжение: `--first 2 --repeats 9`. После остановки на HTTP 429 в попытке 8 оставшиеся попытки запускались через `--first 9 --repeats 2`. Исторические run IDs не перезаписывать; независимое повторение использует новую папку, прежний общий ledger и заново проверенные тарифы. Секретный ключ задаётся через окружение или защищённый файл.
