## Что восстановлено из истории

В прежнем диалоге статья посвящалась программной организации работы с LLM:
извлечению редакционного опыта из DOCX, хранению правил в шаблоне и их
массовому применению небольшими моделями без дообучения весов. Перечитаны
сохранённые сообщения пользователя в исходном порядке, особенно 37, 41,
42, 51 и 60. [Замысел и соответствие разделам](manuscript-020-brief.md).

[Полная новая рукопись](manuscript-reconstructed.md) содержит около 3400 слов,
две авторские схемы, три таблицы и восемь библиографических записей. Семь
внешних источников проверены по страницам издателя, arXiv, ACL Anthology и
Ecma; восьмой — точная версия нашего исследовательского репозитория.
Служебные сведения не вставлены вместо авторства. Это заново написанная
статья, не найденные байты утраченной рукописи.

В статье объясняются метод, формализация, архитектура, корпус, метрики,
этапы оптимизации, отрицательные результаты и угрозы валидности. Сведения
об утраченном корпусе 010–016 не превращены в подтверждённые измерения.
Для подачи ещё нужны независимые опыты, авторские реквизиты и сверка
полного состава материалов с требованиями выбранной редакции.

## Перенос новой статьи

Источник создан нашим генератором в Courier New, на Letter, с произвольной
типографикой и переставленными частями аннотации. Модель видела исходные
структурные подсказки DOCX; это не чистый нейтральный I1. Эталон пользователя
проверен по известному SHA-256; наблюдения выбраны исследователем для
русскоязычной статьи. Чужие тексты и авторы в результат не копировались.

- Сохранён текст всех блоков, 3 таблицы, 2 рисунка и 6 ресурсных частей,
  включая relationships и numbering; проверены научные сигнатуры сборщика.
- Порядок частей аннотации восстановлен.
- Первоначальная проверка свойств дала 309/328: оставался источник наследования
  line из docDefaults. После исправления — 328/328 и совпадающая геометрия
  страницы. Это подборка проверяемых свойств, не полный норматив издания.
- Число страниц изменилось с 11 до 10 после исправления интервалов.
  PDF содержит настоящие ArialMT/Arial-BoldMT и TimesNewRomanPSMT/BoldMT.
- Выделение шапки таблицы, одинарная библиография и интервалы аннотации
  теперь соответствуют выбранным наблюдениям. В коротком пробнике раньше
  шапка была обычной, а библиография имела интервал 1,5.
- У новой статьи нет независимого пиксельного gold. Совпадение её страниц
  с другой статьёй не измеряется и не требуется.
- Автоматический результат остаётся draft из-за отсутствия авторов.

Отдельная редакторская копия `manuscript-reviewed.docx`: подсказка об авторах
переведена на русский, короткая таблица 3 удержана целиком на странице.
Это две явные правки представления после автоматической сборки, не результат
модели и не автоматически извлечённое правило шаблона. Научный текст не
изменялся. Все 10 итоговых страниц проверены; 5 неизменившихся страниц
совпадают побайтово с уже просмотренными PNG автоматического результата.

Локальные файлы находятся в `artifacts/transfer020/manuscript/`: source.docx,
source.gold.json (только оценщик), model-plan.json, formatted.docx,
report.json, format-audit.json, manuscript-reviewed.docx и reviewed-render/.
Сохранены также первоначальный результат и неудачная проверка интервалов.

## Регрессия и воспроизводимость

92 unit/integration тест; 22 сценария / 95 шагов. На неизменном synthetic-v1
сохранены 152/152 роли, 7/7 содержимое и 6/6 пиксельных пар. Четыре пары
используют точные Arial/TNR; две Calibri — общую подмену, как в 019.

```bash
python -m unittest discover -s tests
behave docs/product/scenarios/research-pilot.feature docs/product/scenarios/structure-web.feature
python scripts/build_manuscript020.py --output artifacts/new-manuscript/source.docx
python scripts/benchmark_recovery019.py --output artifacts/new-regression
```

Генератор не читает эталон. Его gold-файл предназначен только оценщику.
Извлечённый профиль, реальные DOCX, сохранённый модельный ответ и prompt
хранятся закрыто. Повторная сборка по сохранённому ответу не является новой
проверкой модели. Ключи и шрифтовые файлы в архив данных не включаются.
Публичная версия кода 020 не устанавливалась на сервер: там остаётся ранее
проверенный релиз 019. Этот отчёт не заявляет новое развёртывание.
